- `URL 보기`, `새 탭에서 열기`, `원본 주소`가 각각 제공된 SVG 의미에 맞는 아이콘을 사용하도록 액션 매핑을 분리했습니다.

## 1.4.7 변경 내역 (2026-10-26) — 디자인 탭 아이콘 정합성 보정

- 제공된 디자인 말풍선 SVG를 디자인 탭·감사 섹션 아이콘에 적용해 아이콘 세트의 의미와 형태를 일치시켰습니다.

## 1.4.6 변경 내역 (2026-10-26) — SVG 아이콘 시스템·실제 글꼴 미리보기

- 제공된 SVG 아이콘 세트를 선택·원본 주소·URL 복사·URL 보기·새 탭·원본/JPG/PNG 저장·분할 편집·ZIP 작업에 공통 규격으로 적용했습니다.
- 글꼴 목록은 한 줄짜리 단일 열로 정리하고, 페이지에서 발견한 실제 폰트 파일을 `FontFace`로 로드해 한글·영문 샘플을 해당 서체로 미리 보여줍니다.
- 외부 폰트가 CORS로 차단되는 경우에는 UI가 깨지지 않도록 안전한 대체 서체로 표시합니다.

웹페이지의 **이미지·영상·SVG·글꼴 원본 주소**와 렌더링된 **디자인 토큰**을 찾아 보여주고, 골라서 저장하는 Chromium 확장 프로그램 **렛츠 픽(Let's Pick)** 입니다.
(Chrome, Whale, Edge, Brave, Vivaldi)

## 설치 / 업데이트

1. `chrome://extensions` (웨일은 `whale://extensions`)를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. 처음이라면 **압축해제된 확장 프로그램을 로드합니다**로 이 폴더를 선택합니다.
   이미 설치돼 있다면 Let's Pick 카드의 **새로고침(↻)** 버튼만 누르면 됩니다.
4. 열려 있던 탭은 새로고침하면 가장 확실합니다. (안 해도 아이콘을 누르면 자동으로 연결을 시도합니다.)
5. 확장 아이콘을 눌렀을 때 제목 옆에 `1.4.8`이 보이면 새 버전입니다.

## 사용법 — 세 가지 방법

| 하고 싶은 것 | 방법 |
|---|---|
| 이 페이지의 이미지를 한눈에 보고 골라 저장 | **확장 아이콘 클릭** → 목록에서 체크 → `저장` / `ZIP` / `URL 복사` |
| 페이지 위에 큰 패널로 보기 | 아이콘 팝업의 **페이지에서 크게 보기**, 또는 `Alt+Shift+D` (맥: `⌥⇧D`) |
| 이미지 하나의 원본 주소만 분석 | 이미지를 **Alt(⌥)+클릭**, 또는 마우스를 올리고 `Alt+Shift+S` (맥: `⌥⇧S`), 또는 우클릭 메뉴 |

- 체크하지 않고 버튼을 누르면 **지금 보이는 목록 전체**를, 체크하면 **체크한 것만** 처리합니다.
- **검색창**에 파일명·주소 일부를 입력하면 바로 걸러집니다. **크기 필터**(200/400/800px 이상)로 썸네일·아이콘을 숨길 수 있습니다.
- 패널 단축키: `1`–`4` 기본 메뉴 이동, 디자인에서 `5` 종합·`6` 글꼴·`7` CSS·`8` SVG, `/` 검색, `S` 저장, `C` 주소 복사, 크게 보기에서 `←` `→`, `Esc` 닫기.
  (페이지의 입력창에 글을 쓰는 중에는 단축키가 작동하지 않습니다.)
- 단축키는 `chrome://extensions/shortcuts` 또는 설정(⚙) 화면에서 바꿀 수 있습니다.
- **영상 저장**: 영상 위에서 ⌥+클릭하거나 「영상」 탭을 열면, 영상마다 저장 방법(원본 파일 / DASH → MP4 / HLS → MP4 / 녹화 / DRM 보호)과 화질, 설명이 나옵니다. 맨 위 항목이 가장 좋은 방법입니다.
- 설정(⚙): Alt+클릭 켜기/끄기, Alt+클릭한 영상 바로 저장, 패널 위치(왼쪽/오른쪽), 저장 폴더 이름.

## 1.1.0 변경 내역 (2026-10-08) — 영상 저장 강화

**영상마다 "어떻게 저장되는지"를 보여줍니다**
- 영상 탭에 영상마다 **원본 파일 / DASH → MP4 / HLS → MP4 / 녹화 / DRM 보호** 표시와 화질(예: 1080p), 코덱, 소리 포함 여부, 한국어 설명을 보여줍니다.
- 지금 재생 중인 영상이 맨 위, 가장 좋은 저장 방법이 먼저 나옵니다. `저장` 한 번이면 그 방법으로 저장됩니다.

**플랫폼별**
- **인스타그램**: 릴스·피드 영상의 **원본 MP4(소리 포함)** 를 바로 저장합니다. (이전: 잠김/저장 불가)
- **페이스북**: 영상의 HD·SD 원본 MP4를 화질별로 골라 저장합니다. 1080p는 AV1 코덱인 경우가 있어 안내를 붙였습니다. (이전: 잠김/저장 불가)
- **HLS(.m3u8) 스트림**: 조각 파일을 모두 받아 **하나의 MP4**로 합칩니다. 화질 선택, AES-128 암호화 조각 지원. 새 탭에서 진행률이 보입니다.
- **DASH(.mpd) 스트림**: 영상·소리 트랙을 받아 **하나의 MP4**로 합칩니다. 기본은 1080p 이하 중 가장 좋은 화질이고, 4K 등은 목록에서 고를 수 있습니다.
- **유튜브**: 유튜브는 영상 주소를 외부에서 받을 수 없게 막아 두어서(SABR 방식), 이전처럼 "저장됨"이라고 나오고 실제로는 실패하는 대신 **재생하면서 녹화해서 MP4로 저장**합니다. 영상 길이만큼 시간이 걸리고, `지금 저장`으로 중간에 끝낼 수도 있습니다.
- **그 밖의 사이트**: `<video>` 원본 파일은 바로, 스트림은 합쳐서, 그래도 안 되는 영상(blob)은 녹화로 저장합니다.
- **DRM(넷플릭스·디즈니+ 등 보호 영상)**: 「DRM 보호」로 표시하고 저장하지 않습니다. 녹화해도 검은 화면이 되기 때문입니다.

**고친 점**
- 실패한 다운로드(403 등)를 "저장됨"으로 잘못 알리던 문제 수정 → 실제 결과를 확인해서 알려 줍니다.
- 제목에 특수문자가 있으면 저장이 실패하던 문제 수정.
- 스트림의 작은 조각 파일(수백 바이트)이 영상 목록에 섞여 잘못 저장되던 문제 수정.
- ⌥+클릭으로 영상을 바로 저장할 때는 녹화가 갑자기 시작되지 않게 했습니다(녹화는 버튼으로만).

**한계**
- 생방송 DASH는 저장하지 않습니다. 생방송 HLS는 지금 받을 수 있는 구간만 저장됩니다.
- 스트림은 내려받는 동안 메모리에 모았다가 저장하므로, 아주 긴 영상(수 GB)은 오래 걸리거나 실패할 수 있습니다.
- AV1·VP9 코덱 영상은 오래된 Mac의 QuickTime에서 안 열릴 수 있습니다(크롬·웨일·VLC에서는 재생됩니다).

## 1.0.1 변경 내역 (2026-10-08)

- **Alt(⌥)+클릭 복구**: 확장을 업데이트(새로고침)하면, 이미 열려 있던 탭에는 연결이 끊긴 옛 코드가 남아 있었습니다. 이 옛 코드가 ⌥+클릭을 가로챈 뒤 아무것도 열지 못해서 "알트클릭이 안 되는" 것처럼 보였습니다.
  - 이제 설치·업데이트 직후 열려 있는 모든 탭에 새 코드를 바로 넣어 줍니다. 탭을 새로고침하지 않아도 됩니다.
  - 옛 코드가 클릭을 가로채더라도 새 코드가 이어받아 패널을 엽니다.
  - 앞으로는 연결이 끊긴 옛 코드가 클릭을 가로채지 않고 양보합니다.
- ⌥+클릭 동작 자체(이미지·투명 덮개 아래 이미지·영상·링크 이미지·배경 이미지 인식)는 0.8.6/0.9.0과 같습니다. 설정에서 「Alt(⌥)+클릭」은 기본으로 켜져 있습니다.

## 1.0.0 변경 내역 (2026-10-08)

**쓰기 편하게**
- 팝업 전면 개편: 이미지·영상·SVG 탭, 썸네일 그리드, 검색, 크기 필터, 체크해서 고르기, 항목별 `저장 / 복사 / 열기`.
- 팝업에서 바로 **페이지에서 크게 보기** 버튼과 **설정** 버튼.
- 페이지 패널: 검색·크기 필터·정렬(큰 것부터/페이지 순서), 체크 선택, `URL 복사` 일괄 버튼, 패널 위치 바꾸기(⇆), 하단 단축키 안내.
- 저장·복사 결과를 화면 아래 알림으로 보여줍니다. 실패하면 이유를 알려줍니다.
- 우클릭 메뉴에 「이 페이지 미디어 모두 보기」 추가.
- 새 단축키 `Alt+Shift+D` (페이지 전체 보기). 기존 `Alt+Shift+S`는 이제 실제로 작동합니다(이전엔 연결이 빠져 있었음).
- 큰 보기에서 `←` `→`로 넘기기, `Esc`는 맨 위 창부터 하나씩 닫기.

**더 잘 찾기**
- 그림자 DOM(웹 컴포넌트) 안의 이미지·SVG, CSS 배경 이미지, `data-srcset` 지연 로딩, 확장자 없는 이미지 주소, 큰 GIF, `<video><source>`·포스터까지 찾습니다.
- 팝업은 페이지 안의 iframe(프레임)까지 모두 합쳐서 보여줍니다.
- 확장 프로그램을 설치/새로고침하기 전에 열려 있던 탭도 자동으로 연결합니다.

**버그 수정**
- HTML 이스케이프 함수가 아무것도 바꾸지 않던 문제(주소에 `"`·`<`가 있으면 화면이 깨지던 문제) 수정.
- 패널이 열려 있으면 0.9초마다 목록을 다시 그려 스크롤이 튀고 선택이 풀리던 문제 수정 → 새 항목만 뒤에 추가.
- 파일 크기를 알아내려고 이미지·**영상 파일 전체를 내려받던** 문제 수정 → 헤더만 확인, 화면에 보이는 것만, 결과 캐시.
- 인스타그램 댓글창처럼 편집 가능한 영역에 `s`, `c`, `1` 등을 입력하면 저장·복사가 실행되던 문제 수정.
- 숫자 `1` 키로 「선택」 탭이 열리지 않던 문제 수정.
- `모두 저장 (N)` 표시 개수와 실제 저장 개수가 달랐던 문제 수정.
- 지연 로딩 이미지가 자리표시 이미지 크기(1×1)로 표시되던 문제 수정.
- 저장 파일명에 확장자가 빠지던 문제 수정.
