WHAT YOU CAN PICK

찾는 것부터 저장하는 순간까지,
한 흐름으로 이어집니다.

개발자 도구를 열고 코드를 헤매지 않아도 됩니다. 알트클릭 한 번으로 페이지 안의 미디어를 수집하고, 필요한 파일만 골라보세요.

페이지 미디어 탐색

현재 페이지의 이미지·영상·SVG를 자동으로 모아 탭별로 보여줍니다.

DISCOVER · FILTER

메타데이터 확인

파일명, 원본 용량, 가로·세로 크기, 해상도, 포맷, 주소를 함께 확인합니다.

NAME · SIZE · FORMAT

원하는 포맷으로 저장

이미지는 JPG·PNG·WebP, 영상은 지원 가능한 원본 형식으로 저장합니다.

JPG · PNG · WEBP · MP4

긴 이미지 슬라이스

상세페이지처럼 긴 이미지는 가로선을 추가하고 여러 장으로 나눠 내보냅니다.

SLICE · EXPORT

라이트박스 미리보기

선택한 파일을 큰 화면에서 확인하고 앞뒤 항목을 넘겨 비교할 수 있습니다.

PREVIEW · NAVIGATE

주소를 바로 활용

원본 URL 보기·복사·새창 열기를 통해 다른 작업으로 바로 이어갈 수 있습니다.

COPY · OPEN · SHARE

HOW IT WORKS

알트클릭 한 번,
네 단계로 끝납니다.

페이지를 이동할 필요 없이, 보고 있는 콘텐츠 위에서 바로 시작하세요.

01

알트클릭

이미지나 영상 위에서
Alt 키를 누른 채 클릭

02

자동 수집

페이지에서 발견한 소스를
유형별로 정리

03

확인·선택

메타데이터와 원본을
확인하고 필요한 항목 선택

04

저장·재사용

URL 복사 또는 파일 저장
다음 작업으로 바로 이동

작은 팁 이미지가 여러 장인 게시물은 팝업에서 항목을 넘겨가며 각각의 원본과 정보를 확인할 수 있습니다.

GET STARTED

설치부터 사용까지,
처음 한 번만 익히면 돼요.

GitHub에서 ZIP을 받고 브라우저에 불러온 뒤, 원하는 페이지에서 바로 사용하세요.

설치 방법
  1. 1
    ZIP 다운로드

    최신 버전 받기 버튼을 눌러 파일을 내려받습니다.

  2. 2
    압축 해제

    ZIP을 원하는 폴더에 풀어 둡니다.

  3. 3
    확장 프로그램 로드

    chrome://extensions에서 개발자 모드를 켜고 압축해제된 확장 프로그램을 불러옵니다.

사용 방법
  1. 1
    웹페이지 열기

    이미지·영상·SVG가 있는 페이지로 이동합니다.

  2. 2
    Alt + 클릭

    원하는 미디어 위에서 Alt 키를 누른 채 클릭합니다.

  3. 3
    Let's Pick에서 처리

    탭을 고르고 URL 보기·복사·저장·변환 기능을 사용합니다.

SEE IT IN ACTION
